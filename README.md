## Not mirrored

The **AMD HIP SDK** installer is not mirrored here because of its size (~1.5 GB) and AMD's EULA. The bootstrapper falls back between two official AMD download URLs instead:

- [HIP SDK for Windows](https://www.amd.com/en/developer/resources/rocm-hub/hip-sdk.html)
- [AMD EULA](https://www.amd.com/en/developer/resources/rocm-hub/eula/licenses.html)
