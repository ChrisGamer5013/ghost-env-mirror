# Ghost Environment Mirror

Backup download mirror for the Ghost AMD environment bootstrapper.

Assets are published under the [v1 release](https://github.com/ChrisGamer5013/ghost-env-mirror/releases/tag/v1).

| File | Upstream |
| --- | --- |
| `doom1.wad` | DOOM shareware IWAD |
| `zluda-windows-v6.zip` | vosen/ZLUDA v6 |
| `chocolate-doom-3.0.1-win32.zip` | chocolate-doom 3.0.1 |
| `hipify-perl` | ROCm/HIPIFY 6.1.0 |
| `Ghost_Track_4.mp3` | SoundHelix Song 4 |
| `strawberry-perl-5.42.2.1-64bit-portable.zip` | Strawberry Perl 5.42.2.1 portable |

The AMD HIP SDK installer is not mirrored here because of its size (~1.5 GB) and AMD's EULA. The bootstrapper falls back between two official AMD download URLs instead.
